# Completion Gates

- [ ] Clean setup documented; build, typecheck and tests pass.
- [ ] Durable storage and migrations before business data is called production.
- [ ] Authentication and cross-owner authorization tests pass.
- [ ] Money uses integer minor units and explicit currency.
- [ ] Payment status is server-verified/idempotent.
- [ ] Session uses authoritative activation timestamps.
- [ ] Gateway commands and accounting are real, observed and audited.
- [ ] Unsupported Android hotspot features are honestly disclosed.
- [ ] UI handles loading, empty, offline, failure and partial integrations.
- [ ] No page-level horizontal overflow; shared design tokens centralized.
- [ ] Privacy, secret redaction, AI budget and permission controls tested.
- [ ] Free-first routing follows provider limits and terms.
- [ ] Duplicate events, races and provider failures tested.
- [ ] Monitoring, backups and restore plan documented.
- [ ] Real payment/gateway/device tests explicitly PASS or NOT TESTED.
- [ ] Status/changelog reflect evidence.

Truth labels: IMPLEMENTED, UNIT-TESTED, INTEGRATION-TESTED, DEVICE-TESTED, PROVIDER-VERIFIED, NOT TESTED, BLOCKED. Never conflate them.
